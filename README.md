# HTB-Machine-Writeups
Detailed write-ups of retired HackTheBox machines: enumeration, exploitation, privilege escalation, and lessons learned.

This repository contains write-ups for retired HackTheBox machines I've worked through as part of my offensive security learning path. Each write-up follows the same structure: reconnaissance, initial foothold, privilege escalation, and key takeaways, so you can see not just what worked, but why. Only retired machines are documented, in line with HackTheBox's rules on sharing solutions.
